# AutoCAD-Electrical-Motor-Control-Panel
Complete electrical control panel design created using AutoCAD Electrical with schematic and panel layout drawings.

This repository contains an electrical control panel designed using AutoCAD Electrical.

The project includes:

- Electrical schematic
- Panel layout
- Standard AutoCAD Electrical components
- Wire numbering
- Component tagging
- Industrial electrical documentation

## Software Used

- AutoCAD Electrical
